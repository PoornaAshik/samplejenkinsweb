🚀 Sample Jenkins Web Application

Welcome!

This is your Maven-based Java web application ready for Jenkins CI/CD pipeline testing and deployment.

Application Details:
  • Technology: Java with Maven
  • Build Type: WAR (Web Application Archive)
  • Testing Framework: JUnit
  • CI/CD: Jenkins Ready

Available Endpoints

  • GET /hello - Test servlet endpoint
  • GET / - This welcome page

mvn test
